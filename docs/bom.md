이 파일은 `uv run python -m horibot_design.bom`이 [data/purchases.toml](../data/purchases.toml)에서 만든다. 고칠 때는 데이터 파일을 고친다. 구매 방식은 [0004](decisions/0004-purchasing.md), 가진 것은 [hardware.md](hardware.md#가진-것)에 있다.

## 예산

| | 값 |
|---|---|
| 받은 것 | 434,198원, 값 모름 1개 |
| 배송 중 | - |
| 지금 주문할 것 | 값 모름 1개 |
| 나중에 살 것 | - |
| **합** | **434,198원, 값 모름 2개** |

- 예산은 300,000원 안팎이고 서보도 들어간다. 조금 넘는 것은 괜찮고, 수십만 원 차이가 나면 다시 생각한다 ([0004](decisions/0004-purchasing.md)). "필요해지면" 품목은 아직 살지 몰라서 넣지 않는다.
- 원화로 값을 아는 것만 빼면 134,198원 넘는다. 달러 값과 값 모름은 아직 들어가지 않았다.
- 값은 확인한 때의 값이다. 지금 주문할 것의 값은 주문할 때 다시 본다.
